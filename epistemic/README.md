# MVO — Minimum Viable Oracle, the Lean formalization

Lean 4.35.0 model of research.phext's epistemic registry: every
claim-bearing unit carries one **Status** (True / False / Unknown /
Fiction) assigned through a **Basis** that constrains which status it
may hold, and the registry's accuracy — unique ids, every entry
basis-conformant, receipt-backing implied by the basis table — is
machine-checked, along with the legality of every way the registry
can change. Design: `~/workspace/custom-skills/minimum-viable-oracle/SKILL.md`
(charter rule 14 of the R&D tracker).

The honesty boundary: Lean proves the *bookkeeping* — classification
exactly once, no True without a receipt of the right kind, statuses
moving only along legal edges, restructuring unable to break any of
that. Whether a receipt-backed True is true in the world rests on the
receipts themselves.

## Layout

| file | contents |
|---|---|
| `Mvo/Basic.lean` | `Status`, `Basis`, `Entry`, the `allowed` table, `AccurateProp`, the decidable checker `accurate` + `accurate_sound`, `empty_accurate` |
| `Mvo/Transitions.lean` | `LegalTransition` (identity + the six receipt-licensed edges), `LegalTransition.id_eq`, `LegalTransition.conformant`, `replaceById`, `replace_preserves` |
| `Mvo/RegistryOps.lean` | `enter_preserves` (ingestion), `removeById`, `retireEntry`/`retire_preserves`, `mergeEntries`/`merge_preserves`, `splitEntry`/`split_preserves` |
| `Mvo/RegistryData.lean` | `currentRegistry` — the data the instance theorem proves about (the REAL registry, adopted 2026-11-07; see its header for source and the generator format contract) |
| `Mvo/Instance.lean` | `currentRegistry_accurate : AccurateProp currentRegistry`, proved via the checker (`accurate_sound (by decide)`) |
| `checks/Axioms.lean` | `#print axioms` trust-surface check; run with `lake env lean checks/Axioms.lean` after a build |

Everything is in namespace `Mvo`. No `sorry` anywhere; the checker is
`by decide` / explicit proof only — no `native_decide`.

`set_option maxRecDepth 32768` at the top of `Mvo/Instance.lean`:

recursion depth without it. To re-adopt after any ingestion: re-run
`extract_registry.py` (it asserts the phext sha in `EXPECTED_SHA` —
update it to the new build first), regenerate, rebuild.
